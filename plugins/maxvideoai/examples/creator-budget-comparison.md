# How can I compare AI video models and price a project before generating?

Use `$plan` to compare live executable model options and named project budgets without spending credits. Select a concrete request only after the trade-offs make sense; only `$generate` can prepare its fresh exact quote and wait for explicit approval.

## What is the intent?

Compare current AI video models for one creator project, understand the quality, speed, control, and budget trade-offs, and stop before paid generation.

![MaxVideoAI model selector and completed production video framed as a comparison workflow](../assets/demos/model-choice-and-budget.webp)

*This visual proves current MaxVideoAI product selection and a completed result are visible together. It does not prove a budget, exact quote, approval, host session, or permanent model recommendation.*

## What prompt can I copy?

**Prompt to copy**: “Compare current AI video models for a short creator campaign. Build a quality-first named budget and a genuinely comparable lower-cost named budget. Explain the trade-offs and stop before preparing paid work.”

```text
Useful inputs: number of shots, shot durations, format, reference needs, creative priority, and project budget.
```

## What is the expected MaxVideoAI behavior?

`$plan` reads live model facts, recommends executable options, and calculates named budgets for comparable shot plans without spending credits. It should explain why each option fits this project instead of calling one model permanently superior.

When you select a concrete shot, `$generate` validates the current model and mode, prepares the selected settings, and returns the fresh exact quote. It then stops for explicit approval.

**Example**: Model capabilities, availability, and prices remain live facts; this example does not freeze them.

## Why use `$plan` before `$generate`?

`$plan` answers a project question: which current route fits the brief and named budget? `$generate` answers a transaction question: what is the exact quote for this selected request right now?

```text
Project budget ≠ exact generation quote
Named comparison ≠ authorization to spend
```

## What if the response is lost after approval?

Recover the accepted job or inspect recent generations before considering another paid request. Do not reuse the old confirmation. If the job is refunded, that authorization is closed; a replacement requires a fresh exact quote and new explicit approval.

**Example**: “Check the accepted job and recover its outcome before you prepare anything new.”

## What remains in the MaxVideoAI Library?

Private references selected for supported workflows remain in the connected MaxVideoAI Library. Completed results return to that Library, so the workflow can present the owned result later without treating a lost response as a reason to regenerate.
