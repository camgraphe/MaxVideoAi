# Security

## Supported version

Only the latest published MaxVideoAI plugin release is supported. The package
contains no embedded access secret, OAuth token, model catalogue, pricing table, or customer
data. Authentication is completed directly with MaxVideoAI over OAuth.

## Report a vulnerability

Please report suspected vulnerabilities privately to
[security@maxvideoai.com](mailto:security@maxvideoai.com). Do not include live
credentials, private customer media, or payment data in the report. We will
acknowledge a valid report and coordinate remediation before public disclosure.

## Verify a release

Each release includes a SHA-256 file for the ZIP archive and a `checksums.json`
file for every packaged source file. Compare these values before installing an
archive obtained outside the official MaxVideoAI GitHub release.
