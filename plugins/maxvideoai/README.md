# MaxVideoAI plugin package

This local source package gives Codex and Claude the same MaxVideoAI skill and
remote MCP connection definition. The host remains the creative collaborator;
MaxVideoAI provides current facts, estimates, quotes, and generation state.

The package intentionally contains no copied model catalogue, static pricing,
or embedded interface. Live MCP results are authoritative.

This branch package is for local structural validation. It does not establish
online availability, OAuth operation, or successful loading by either host.

See [MaxVideoAI MCP](https://maxvideoai.com/mcp) for the product destination.
