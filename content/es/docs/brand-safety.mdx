Los proveedores de modelos aplican sus propios controles de contenido. Un proveedor puede rechazar un prompt, una referencia de imagen, vídeo o audio, o un resultado generado. Los controles y las entradas admitidas varían según el modelo y el modo de generación.

### Cuando se bloquea una solicitud

1. Abre los detalles del trabajo y consulta su estado y mensaje de error.
2. Revisa el prompt y las referencias según las restricciones del modelo seleccionado. Utiliza medios que tengas permiso para usar.
3. Corrige las entradas no admitidas o inapropiadas antes de preparar una nueva solicitud y comprueba el nuevo precio antes de generar.

### Antes de utilizar el resultado

Revisa los medios generados antes de publicarlos o entregarlos, especialmente si incluyen personas, marcas o información personal. Una generación completada no garantiza que el resultado sea adecuado para el uso previsto.

Si falla una generación de pago, consulta los detalles del trabajo y tu billetera para comprobar el estado del reembolso. Si necesitas ayuda para entender un error, incluye el ID del trabajo al contactar con soporte.
