MaxVideoAI conecta un asistente con los mismos modelos, créditos, referencias, trabajos y medios privados del sitio. ChatGPT, Claude o Codex prepara la película; MaxVideoAI aporta capacidades y precios actuales, valida la solicitud y genera únicamente después de que apruebes el precio exacto.

## Dirección del servidor MCP

Usa este recurso Streamable HTTP cuando un cliente solicite una dirección MCP manual:

```text
https://api.maxvideoai.com/mcp
```

No agregues tokens, parámetros, contraseñas ni claves API. El cliente abre MaxVideoAI en el navegador para iniciar sesión y dar consentimiento OAuth 2.1 con `openid,email,profile`. MCP es el mecanismo técnico; para el cliente es el plugin o conector de vídeo con IA de MaxVideoAI.

## Conectar la cuenta

1. Elige MaxVideoAI en ChatGPT o Codex, añádelo como conector personalizado en Claude o introduce la dirección MCP remota.
2. Inicia sesión en tu cuenta MaxVideoAI desde el navegador.
3. Revisa y aprueba la conexión.
4. Vuelve al asistente y pídele que compruebe tu cuenta MaxVideoAI.

OAuth nunca entrega tu contraseña, datos de pago ni acceso a la base de datos. El sitio y el asistente conectado utilizan la misma billetera de usuario y la misma biblioteca privada.

La compatibilidad se registra por cliente. Claude Desktop `1.37937.1` completó OAuth, cuenta, catálogo, presupuestos, cotización exacta, medios, recuperación, carga y recarga. Codex CLI `0.149.0-alpha.4.3` completó OAuth, cuenta, catálogo, presupuestos, cotización exacta y recarga. ChatGPT desktop y Claude Code mantienen una comprobación final propia antes del lanzamiento.

## Qué debe hacer el asistente

El asistente conserva la conversación creativa: brief, guion, planos, prompts e ideas de referencia. Debe usar MaxVideoAI para hechos cambiantes y acciones de cuenta:

- llamar a `list_models` y `get_model_details` en lugar de confiar en su memoria;
- preguntar solo decisiones que cambien calidad, presupuesto, duración, audio o referencias;
- respetar un modelo elegido por el usuario si es compatible;
- si el usuario duda, mostrar primero el mejor modelo ejecutable y alternativas más económicas creíbles;
- usar `calculate_project_budget` para presupuestar películas completas comparables con las mismas hipótesis de intentos;
- usar `prepare_generation` cuando la solicitud final esté lista;
- esperar una aprobación explícita del precio exacto antes de `confirm_generation`.

La calidad no es una caja «económico/equilibrado/premium». En proyectos con varios planos, el asistente puede comparar una propuesta de máxima calidad con alternativas de uno o varios modelos, justificando cada elección. Los intentos creativos son escenarios facturables y deben aparecer por separado.

## Herramientas

| Herramienta | Función | ¿Escribe o gasta? |
| --- | --- | --- |
| `get_account_status` | Leer conexión, saldo, prueba, límites y destinos seguros de cuenta. | No. |
| `list_models` | Encontrar modelos de imagen y vídeo ejecutables por modo y necesidad. | No. |
| `get_model_details` | Leer ajustes, funciones de referencias, límites, evidencia y datos de precio de un modelo. | No. |
| `recommend_models` | Relacionar el brief con una lista corta de modelos y explicar diferencias. | No. |
| `calculate_project_budget` | Comparar de una a cuatro propuestas completas con precios actuales. | No. Una estimación no es una cotización. |
| `list_media` | Listar imágenes, vídeos o audios privados listos de la cuenta. | No. |
| `create_reference_upload_link` | Crear un paso privado y temporal de MaxVideoAI para subir un archivo. | Crea un paso, nunca un trabajo del proveedor. |
| `prepare_generation` | Validar modelo, ajustes, referencias, propiedad y saldo; devolver un precio exacto temporal. | Sin cobro ni generación. |
| `confirm_generation` | Aprobar una cotización exacta y enviar su trabajo de manera idempotente. | Sí, solo tras aprobación explícita. |
| `get_generation_status` | Leer progreso, resultado, fallo y reembolso de un trabajo. | No. |
| `list_recent_generations` | Recuperar trabajos recientes sin crear duplicados. | No. |
| `create_topup_link` | Abrir una recarga segura de créditos MaxVideoAI por el importe necesario. | El pago ocurre en MaxVideoAI. |

Los flags de publicación de producción deciden qué herramientas con escritura se exponen. La respuesta `tools/list` del cliente es la fuente autorizada.

## Referencias de imagen, vídeo y audio

El asistente puede imaginar, crear o elegir referencias. MaxVideoAI acepta y guarda los medios sin quitar libertad creativa a ChatGPT, Claude o Codex.

Usa `list_media` para un elemento ya guardado en la biblioteca MaxVideoAI. Para un archivo nuevo, llama a `create_reference_upload_link` con `image`, `video` o `audio`; el usuario abre la página HTTPS devuelta, sube el archivo y el asistente vuelve a listar ese tipo de medio.

Llama siempre a `get_model_details` para el modo elegido. Devuelve tipos, funciones, orden, cantidades, formatos, tamaños y duraciones aceptadas. Nunca copies reglas de otro modelo. Las URL privadas y los `assetId` estables permanecen dentro de la cuenta.

Seedance 2.5 funciona mediante su ruta ModelArk para texto a vídeo, imagen a vídeo, referencias a vídeo y extensión. El vídeo a vídeo directo que depende de BytePlus LAS no se expone mientras no exista acceso a LAS; esa limitación no desactiva los modos Seedance 2.5 compatibles.

## Presupuesto, precio exacto y aprobación

`calculate_project_budget` es gratuito. Estima una película según propuestas, planos, duraciones, modelos e intentos previstos. No reserva capacidad, no cobra créditos y no crea trabajos.

Tras elegir, `prepare_generation` valida todo y devuelve el precio exacto de la cuenta con vencimiento. Muéstralo y espera una aprobación inequívoca. Después llama una sola vez a `confirm_generation` con el identificador de la cotización.

Si faltan créditos:

1. llama a `create_topup_link` para esa cotización;
2. envía al usuario a la página de facturación MaxVideoAI devuelta;
3. cuando confirme la recarga, consulta otra vez `get_account_status`;
4. llama de nuevo a `prepare_generation`, porque la cotización anterior ya no es válida;
5. muestra el precio nuevo y solicita otra aprobación.

El plugin, los consejos y los presupuestos no requieren una suscripción adicional. Las generaciones usan los créditos pay-as-you-go existentes de MaxVideoAI.

## Trabajos, biblioteca, fallos y reintentos

Un trabajo aceptado todavía no está terminado. Usa `get_generation_status` para uno conocido o `list_recent_generations` para recuperarlo. No vuelvas a enviar una generación pagada por un simple timeout.

Las imágenes y vídeos correctos se guardan en la misma biblioteca privada MaxVideoAI del sitio. Usa únicamente el destino de resultado, workspace o biblioteca devuelto por MaxVideoAI.

Ante un fallo técnico definitivo, explica el estado de fallo y reembolso. No reintentes automáticamente. Un nuevo intento creativo es de pago y exige una cotización y aprobación nuevas.

## Crédito inicial

Una cuenta elegible y verificada puede recibir una generación Seedance 2 Mini cuando la promoción está activa. Es un derecho promocional único, no dinero reutilizable. Comprueba siempre su estado con `get_account_status`. El audio puede permanecer activo sin cambiar el precio promocional si el preset actual lo permite.

## Desconectar y revocar

1. Elimina MaxVideoAI del cliente.
2. Abre [las conexiones de la cuenta MaxVideoAI](/account/connections).
3. Revoca la autorización correspondiente.
4. Comprueba que la siguiente llamada protegida exija una aprobación nueva.

## Privacidad y seguridad

- El correo de la cuenta se omite de los resultados.
- Prompts, tokens, secretos, URL completas, medios privados y datos de pago se excluyen de la analítica de adquisición.
- Las respuestas autenticadas usan `Cache-Control: private, no-store`.
- Las cotizaciones vencen, el envío pagado es idempotente y los límites del servidor siguen activos.
- El asistente no puede afirmar que un medio esté automáticamente autorizado para publicación o uso comercial.

## Solución de problemas

### El navegador vuelve a 127.0.0.1 y no conecta

El listener temporal del cliente ya no está activo o usaba otro puerto. Mantén el cliente abierto, reinicia la conexión desde él y aprueba la solicitud nueva. No reutilices una URL de autorización anterior.

### Vuelve a pedir autenticación

El acceso OAuth venció o fue revocado. Conecta de nuevo y aprueba en el navegador. Nunca pegues un bearer token en la dirección MCP.

### `HTTP 401 / JSON-RPC -32001`

La solicitud no tiene autorización válida. Deja que el cliente siga el desafío `WWW-Authenticate` y la URL `resource_metadata`.

### `INTERNAL_ERROR`

Conserva el `correlationId`, detén los envíos repetidos y contacta con soporte si el error continúa.

### Falta un modo

Consulta otra vez `get_model_details`. Un modelo puede usar varias rutas de proveedor: una ruta no disponible no significa que todo el modelo esté desactivado.

## Límites actuales

No es una API REST de uso general y no entrega claves API de cliente. No controla la timeline Studio, no edita cualquier vídeo fuente, no gestiona callbacks de clientes, no recopila pagos en el chat, no expone modelos ocultos y no aprueba automáticamente medios para publicación.
