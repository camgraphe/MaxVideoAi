## Your scene comes first
The same person, from one shot to the next. Start with the details you cannot afford to lose.

## The shortlist, in detail
1. **[Seedance 2.5](/models/seedance-2-5)** — Combine image, video and audio references to guide a character through a scene up to 30 seconds. Give each reference a clear purpose.
2. **[Kling 3.0 Omni Pro](/models/kling-o3-pro)** — A 1080p option for image-led scenes, reference-guided work and video transformation. Plan what each reference should control.
3. **[MiniMax H3](/models/minimax-h3)** — Generate 5–15 second clips with audio, with output options up to 4K and support for image, video and audio references.
4. **[Wan 3 Prime](/models/wan-3-prime)** — Use opening and ending frames, mix references or extend a clip, with generation lengths up to 30 seconds.
5. **[Grok Imagine Video 1.5](/models/grok-imagine-video-1-5)** — Animate an opening image with generated audio, or explore a scene from text. Both routes offer output up to 1080p.

## Questions before you create
### What is the best model for character consistency?
We keep Seedance 2.5 first for longer scenes with mixed references, followed by Kling Omni Pro for shot-level direction. H3, Wan 3 Prime and Grok 1.5 offer other reference workflows. Compare the same character in each shot; none promises an identical face.

### How many references should I use?
Use only references with a clear purpose. More files help when roles are explicit; unrelated images increase ambiguity.

### Is a face image enough?
Not for strict continuity. Add full-body, wardrobe, and prop references when those details must survive camera and pose changes.
