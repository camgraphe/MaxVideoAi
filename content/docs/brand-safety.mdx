Model providers apply their own content checks. A provider may reject a prompt, a reference image, video or audio, or a generated output. The checks and supported inputs vary by model and generation mode.

### When a request is blocked

1. Open the job details and read its status and error message.
2. Review the prompt and reference media against the selected model’s restrictions. Use media you have permission to use.
3. Adjust unsupported or inappropriate inputs before preparing a new request, then check the new price before generating.

### Before using the result

Review generated media before publishing or delivering it, especially when it includes people, brands or personal information. A completed generation does not guarantee that the result is appropriate for your intended use.

For a failed paid generation, check the job details and your wallet for the refund status. If you need help understanding an error, include the job ID when contacting support.
