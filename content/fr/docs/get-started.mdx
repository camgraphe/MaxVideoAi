1. **Créez votre compte individuel** et connectez-vous pour ouvrir l’espace MaxVideoAI.
2. **Rechargez votre wallet** depuis Facturation avec le paiement sécurisé Stripe Checkout. Payez par carte ; Apple Pay, Google Pay, PayPal ou Link peuvent aussi apparaître selon votre appareil et votre région.
3. **Choisissez un modèle et préparez votre entrée.** Ajoutez un prompt et, si le modèle choisi le permet, une image de référence. Vérifiez le prix affiché avant de lancer la génération.

### Checklist de la première génération

1. Ouvrez l’espace **Vidéo** ou **Image**, puis choisissez un modèle compatible avec votre type d’entrée.
2. Confirmez la durée, la résolution, les références facultatives et le montant *Prix avant génération*.
3. Lancez la génération, suivez son état dans **Jobs** et retrouvez le résultat terminé dans votre bibliothèque.

### Wallet et remboursements

La confirmation d’une génération payante débite votre wallet individuel. En cas d’échec technique, le montant est automatiquement recrédité. Le job et son statut restent visibles dans votre historique.

### Disponibilité MCP

Le [guide MCP public](/fr/docs/mcp) explique comment connecter un client compatible et autoriser votre compte MaxVideoAI. Les outils disponibles et les étapes de confirmation des générations dépendent du client. Vérifiez le mode de connexion compatible avant de commencer.
