## Content changes

1. The platform guide links to the existing image-to-video shortlist when the
   reader has a start and an end image. Capabilities belong to the selected
   model/mode; a three-keyframe demonstration is not evidence for a two-anchor
   workflow.
2. The project-budget guide links to the LTX 2.5 Pro Prompt Lab, matching its
   worked pricing scenario. This helps define the next attempt without promising
   a better success rate.
3. The LTX Pro comparison gains the existing `pricingCreditLink` projection to
   PAYG. The cited Omni/Veo comparisons already have it. Gallery reuse actions
   and existing links to models/comparisons are retained.

Each change is localized in English, French and Spanish. They use existing
paragraphs and link slots; no new layout, pricing algorithm, media or route is
introduced.
