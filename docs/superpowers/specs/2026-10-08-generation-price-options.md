# Compatible generation price options

Approved in conversation on 2026-10-08: Studio and MCP should normally offer three compatible image/video choices with useful price differences when the model is open. Exact model selections stay direct. Fewer compatible choices are honest; no model, reference, duration or resolution constraint may be relaxed to fill a shortlist.

A shared read-only comparison uses the current executable catalog, exact mode projections, owned reference metadata and canonical customer pricing. Explicit settings stay fixed. Unspecified resolution/framing settings use disclosed supported presets. It creates no quotes, wallet reads, reservations or provider jobs. Selection returns to the existing fresh quote and explicit confirmation flow.

Follow-up comparisons may include a baseline model, repriced in the same read. Savings require matching currency and disclose any preset differences. Price never proves quality. Labels and explanations remain brief, including for lip sync. The quote footer invites a different model, resolution, duration or budget and a new quote with a price comparison.

Studio performs comparison in one action without increasing its response allowance. MCP exposes the same bounded service as a read-only tool. Existing certification, capability gates, authorization and recovery contracts remain authoritative. Source changes do not imply production deployment or installed-plugin release.
