Prompt writing tips

Guide each reference

Say which image defines the person, clothing or location. Use up to 10 reference images to guide one output.

Continue from the last edit

Use the previous result as the next reference. Name what must stay, then ask for one change. For an opaque scene, keep Background set to Opaque.

Choose a transparent output

Select PNG and Transparent in Create. Describe the isolated subject and leave space around its edges. JPEG cannot preserve transparency.

  • Check every letter, face and hand in the result before using it.
  • For a video starting frame, keep a readable pose and leave room for motion. Seedream creates the still; animate it in a separate video generation.

FAQ

A few things to know.

What can I create with Seedream 5.5?

Create still images from text or edit with up to 10 reference images. Portraits, scenes between people, campaign images and transparent PNG assets are useful starting points. Each request returns one image.

How do I refine the same scene?

Use the selected image as a reference. State what to preserve and ask for a focused change, then inspect the new result before using it for the next edit.

Can I create a transparent background?

Yes. Choose PNG output and the transparent-background setting. JPEG is suitable for an opaque scene.

Which resolutions and formats are available?

MaxVideoAI offers 1K, 1.5K and 2K, with JPEG or PNG output. Image editing accepts up to 10 references and returns one image; use Lite when you need image sets.

Can I animate the image afterwards?

Save the still and choose a video model for a separate generation. A readable silhouette, clear hands and space around the subject make the opening frame easier to plan.

How much will my image cost?

Select the resolution, format and references in the image workspace. Review the current quote before confirming the request.

Limits & practical advice
  • One generated image per request
  • Choose PNG and a transparent background for an image with an alpha channel.
  • Review rendered text and fine details before publishing.
Responsible image creation
  • Use source images you have permission to edit.
  • Respect consent and rights when depicting real people.
  • Provider safety rules apply to prompts and reference images.
