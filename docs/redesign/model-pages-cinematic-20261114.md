# Cinematic model pages — working plan

Scope: Seedream 5.5 and Seedance 2.5 Flash, coordinated with their model-integration owners. Review in a draft PR before any production release.

## Accepted direction

- English creative previews; production editorial content remains complete in EN/FR/ES.
- Distinct image and video layouts with real MaxVideoAI branding and Geist.
- Dark graphite primary controls, including hover; no orange or bright white hero buttons.
- Put model identity, supported uses, key limits, price access and generation action near the opening proof.
- Preserve current metadata, canonical/hreflang, publication, pricing, examples and comparison owners.
- Seedream demonstrations are real Seedream outputs. Flash start frames are Sunburst images and must never become Flash performance claims or VideoObjects.

## Work sequence

1. Qualify Outreach GSC/Bing observations and map search intent to page content.
2. Coordinate exact integration commits and ownership with the two model chats.
3. Add a typed, exact-locale cinematic presentation through existing model-page loaders.
4. Compose image/video presentation sections while reusing existing commercial and SEO data.
5. Verify contracts, types, lint, build, localized HTML, interactions, media delivery and comparable loading behavior.
6. Prepare a reviewable branch/PR; no merge or production deployment in this task.

## Acceptance evidence

The final review must identify the GSC date range and extraction limits, dependency commits, representative EN/FR/ES URLs, desktop/mobile screenshots, source attribution, real-versus-planned media, canonical/hreflang/schema output and any unresolved provider or price qualification.
