# MCP public claims matrix

This matrix is the publication contract for MCP acquisition copy. A claim may use the allowed wording only when its
live flag is true and the cited evidence is current. Staging, local, design, or protocol evidence does not make a
production claim live. When evidence and a flag disagree, public copy must fail closed.

The prohibited wording column contains examples that must not appear as product assertions. It is policy text, not a
claim that those capabilities exist.

## Publication rule

`indexable` requires `publicIndexing`, transport, OAuth, discovery, paid generation, and reference uploads. Trial remains an independent claim and stays disabled. Integration-specific publication and indexation remain owned by `frontend/config/mcp-integrations.json`. Paid-generation, reference, Audio, and montage claims are independently gated and must not be inferred from a public page alone.
