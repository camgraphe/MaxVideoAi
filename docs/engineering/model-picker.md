`useModelPickerEstimates` separates the complete current request identities from the visible IDs eligible to start work. Scope, tariff and changed-request invalidation remain immediate. Closing releases queued work and real generation still performs its fresh canonical preflight.

The price cell reserves the same width for loading and resolved text so asynchronous results do not change name wrapping or row heights. Stable row keys and the internal scroller remain unchanged. Direct model activation keeps availability, account, upload, storage and stale-context protections; comparison controls and information buttons never select by propagation. Incompatible inputs retire only after the explicit switch's original setup is preserved.
