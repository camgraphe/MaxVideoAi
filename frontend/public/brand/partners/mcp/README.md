# MCP integration marks

These local marks identify third-party MCP hosts; they do not imply endorsement or partnership.

- Claude and OpenAI marks reuse the existing repository assets.
- The OpenClaw mark is a static adaptation of the official OpenClaw Control UI favicon, with its animation removed for a stable marketing surface.
- The n8n symbol follows the official n8n pink (`#EA4B71`).
- Cursor, GitHub Copilot, and Google Gemini paths come from Simple Icons 16.30.0 (CC0-1.0).
- The Microsoft mark uses Microsoft's four-square brand colors to identify the Microsoft Copilot family.

Every mark is stored locally so the marketing pages do not depend on third-party asset delivery.
